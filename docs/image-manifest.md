# Image Manifest

Production imagery for The Nervous System Institute website. All assets live
under `apps/web/public/images/` as optimised WebP and render through
`next/image` (`ResponsiveImage` / `EditorialImage` / `SectionImage`).

Two sources of imagery are used, per the brand art-direction rules:

- **Caroline Reed — real production photography.** Used only on pages where
  Caroline should appear: Home, About, Method, Faculty, Book a Discovery Call,
  Contact, Practitioner Certification and Executive Advisory. Marked
  _(Caroline)_ below.
- **Curated editorial photography.** One cohesive library — editorial,
  natural light, warm neutrals, Scandinavian interiors, minimal, cinematic,
  soft shadows, no text/logos/watermarks. Used everywhere else, and for the
  non-portrait slots (still-life, interiors, nature, workshops) on Caroline's
  pages. Research, Resources and Articles never use Caroline.

Heroes are 1920×1080, standard landscapes 1600×1000, portrait crops 1000×1400;
all cropped with intelligent focal positioning (never stretched).
